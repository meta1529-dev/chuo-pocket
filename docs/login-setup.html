iPhoneのSafariで設定

ログインを再開しやすく

授業データは中大ポケットに、メール連携の設定はSafariの拡張機能に保存します。スマホを閉じても、設定を毎回入力する必要はありません。

初回の準備

  1. App StoreでUserscriptsを入れる。
  2. Userscriptsアプリで保存先を「このiPhone内」のフォルダにします。
  3. iPhoneの設定でSafari → 拡張機能 → Userscriptsを有効にします。
  4. ログイン補助を開く。Safariの拡張機能メニューからUserscriptsを開き、表示されたスクリプトをインストールします。
  5. Gmail（mail.google.com）とCampusSquare（portal.cs.chuo-u.ac.jp）のページで実行を許可します。
  6. Safariで大学に登録したGmailへログインし、「デスクトップ用Webサイトを表示」にします。

この補助は自分のメールを読む権限を使います。パスワードの保存や、大学の認証そのものの省略は行いません。Google・大学への初回ログインは公式画面で行ってください。

いつもの使い方

  1. CampusSquareを開く。メールを「送信」する前の画面まで進みます。
  2. 下に表示される「中大ポケット」でGmailアドレスとアカウント番号を保存します。次回も引き継ぎます。
  3. 「Gmailで自動認証を開始」を押します。開いたGmailで過去の認証メールを確認します。
  4. 案内に従いCampusSquareへ戻ります。新しい認証メールが送信されます。
  5. 「Gmailから番号を取得」を押し、Gmailを前面にして到着を待ちます。
  6. 新しいメールが見つかったら、補助表示の「原文を開いて確認」を1回タップします。原文が別タブに開き、補助が秒単位の受信時刻と大学の署名を確認します。
  7. 確認完了の表示が出たらCampusSquareへ戻ります。新しい番号が公式フォームへ入力・送信されます。「この原文タブを閉じる」を押して通常のGmail画面へ戻ることもできます。

原文のタブが開かない場合は、対象の認証メールでGmailの「その他のメッセージ オプション」→「原文を表示」をタップしてください。

原文を開くタップとCampusSquareへ戻る操作は必要です。iPhoneが画面を閉じている間の処理には依存せず、再び開いたとき保存した進行状況から再開します。期限が切れた認証は、新しく開始してください。

何を記憶する？

  • 授業・教室・課題・シラバス：中大ポケットの端末内保存。設定からJSONバックアップを保存・復元できます。
  • Gmailアドレスとアカウント番号：Userscriptsの端末内保存。
  • 認証の途中の状態：期限付きの認証セッションとして別に保存し、再表示時に再開。
  • 大学のパスワード：このアプリは保存しません。Safariのパスワード自動入力は公式画面で利用できます。
  • 認証番号：取得から入力までの短時間のみ保持。入力時または期限切れ後の再表示時に破棄します。

JSONバックアップに入るのは授業用の保存データです。Gmail連携の設定や認証セッションは入りません。授業データを復元しても、大学やGoogleのログイン状態を復元することはできません。

大学やGoogleがログイン期限を切った場合は公式画面で再認証が必要です。保存した授業データや連携設定は、そのまま残ります。端末変更や閲覧データの削除に備えて、設定から授業データのバックアップを保存してください。

確認状況

大学公式の認証フォーム、Gmailの通常画面と原文表示に合わせた処理を実装しています。iPhone実機でのUserscriptsの許可・原文を開くタップ・タブ切替・番号入力からログイン完了までの一連の動作は未確認です。画面や受信記録を確認できない場合は自動入力を停止し、公式画面での操作を案内します。

認証メール本文は公開サイトへ送信しません。公開するスクリプトにはメールアドレス・学生番号・認証番号は含まれていません。
