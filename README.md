# 中大ポケット

中央大学の授業・教室・課題・シラバスをiPhoneの端末内に保存する、個人用のブラウザアプリです。公開するのはプログラムだけで、学生のデータ・パスワード・認証メールは含みません。

## 閉じても引き継ぐ保存

授業や課題を変更した時点でIndexedDBに保存し、保存が完了してから「保存済み」を表示します。次に開いたとき読み直します。前回の保存内容も端末内に残し、保存に失敗した場合は入力中の画面と最後の保存内容を保持します。既存の保存データは新しい形式へ移行し、読めないデータを空の状態で上書きしません。

設定から「保存データを保護」を実行できます。ブラウザが対応していれば永続ストレージを要求し、許可されたか表示します。ホーム画面に追加して、そのホーム画面版を授業データの保存先に統一してください。Safariタブとホーム画面版の保存領域は、同じ扱いになるとは限りません。端末変更や閲覧データの削除に備えてJSONバックアップも保存できます。

## GmailとCampusSquareのログイン補助

アプリの「取り込み」から「メール連携の設定」を開きます。iPhoneのSafari拡張機能 [Userscripts](https://apps.apple.com/jp/app/userscripts/id1463298887) に、`chuo-pocket-login.user.js` を一度インストールします。保存先は「このiPhone内」にし、GmailとCampusSquareでの実行を許可します。GmailはSafariの「デスクトップ用Webサイトを表示」で利用します。

1. 公式CampusSquareのメールを「送信」する前の認証画面で、下に表示される中大ポケットのGmail設定を保存します。
2. 「Gmailで自動認証を開始」を押します。Gmailで過去の認証メールのIDを確認します。
3. CampusSquareへ戻ると、公式の送信ボタンで新しい認証メールを要求します。
4. 「Gmailから番号を取得」でGmailを前面に開き、メールの到着を待ちます。
5. 新しいメールを確認したらCampusSquareに戻ります。認証番号を公式フォームへ入力して送信します。

Gmailアドレスとアカウント番号は拡張機能の端末内保存に残り、再起動後に引き継ぎます。認証の進行状況も期限付きで保持し、同じ公式フォームであることを確認して再開します。Gmailを前面に開く操作と大学のタブへ戻る操作は必要です。iPhoneが閉じている間のバックグラウンド実行には依存しません。

これは本人のメールに届いた番号を大学の正規の認証へ渡す仕組みです。大学・Googleの初回ログインやパスワード入力は公式画面で行います。大学やGoogleがログイン期限を切った場合、再認証が必要です。授業データや連携設定は、そのまま保持します。大学パスワードの収集・保存や、認証の省略は行いません。

送信元・件名・メールID・受信時刻・Gmailの送信元と署名元を照合します。古いメール、使用済みのメール、複数候補、違う画面では入力を停止します。認証番号は入力まで短時間だけ拡張機能の保存領域に置き、使用時、または期限切れ後の再表示時に破棄します。認証メール本文や番号は公開サイトに送信せず、授業用の保存領域にも入れません。

Gmailが表示する受信時刻は分単位です。送信前に取得したメールID一覧で同じ分の既存メールを除外しますが、Gmailが既存メッセージを後から読み込む場合、秒単位で受信前後を証明できません。実機での取得結果を確認するまでは、認証補助は検証中です。

## 授業データの取り込み

Safariでmanabaの曜日表示の時間割・未提出課題一覧、またはCampusSquareのシラバス詳細を開きます。「取り込み」→「設定手順を見る」の案内に従って、Safariの共有からページを読むショートカットを設定します。取得したデータを中大ポケットに貼り付け、保存前に項目を選びます。ショートカットのクリップボード設定は「ローカルのみ」にします。

授業の手動編集、複数の曜日・時限、課題の締切と完了状態、シラバス本文の保存、JSONバックアップの復元に対応しています。休講・教室変更の自動巡回は実装していません。最新の変更は公式MYスケジュールで確認してください。

## 確認状況

実際のmanabaの時間割・課題一覧・CampusSquareのシラバスと認証フォーム・Gmailの認証通知の構造を確認しています。架空HTMLで認証メールの選別、署名の照合、公式フォームへの送信、ページ再起動後の復元、番号の一度だけの消費を検証しています。

iPhone実機でのUserscriptsの許可・Gmail表示・タブ切替・番号入力からログイン完了までの一連の確認は未完了です。プログラムの検証成功だけで、スマホ単独での動作が完了したとは扱っていません。

## 配信ファイル

ローカルの `dist/` がアプリ本体です。GitHubでは同じ内容を `docs/` に置き、GitHub Pagesの `main` ブランチ・`/docs` から配信します。`data.js` が端末保存、`app.js` が画面、`chuo-pocket-login.user.js` がSafariのメール連携を担当します。外部の分析サービス・アプリサーバーは使用しません。
